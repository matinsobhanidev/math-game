# Math Game

A desktop math game built with Python and Tkinter.

## About
This is one of my early Python projects, created several years ago. It helped me explore programming through a practical math game.

## Features
- Random math questions
- Addition, subtraction, multiplication, and division
- Answer validation
- Correct and incorrect answer counters
- Multiple-choice quiz mode
- Theme changing

## Technologies
- Python
- Tkinter
- random

## How to Run
Make sure Python and Tkinter are installed, then run:

```bash
python math_game.py
```
